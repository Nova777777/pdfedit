# PDF 页面整理

一个**完全本地运行**的 PDF 页面整理工具：排序、删页、旋转、裁剪、统一尺寸、拼版、拆分与合并。
所有文件都只在本机浏览器里处理，**不会上传到任何服务器**，断网也能用。

---

## 一、启动

1. 双击目录里的 **`启动PDF工具.bat`**。
2. 会弹出一个黑色命令行窗口，并自动用默认浏览器打开：
   `http://127.0.0.1:8787/index.html`
3. **使用期间请不要关闭这个命令行窗口**；关掉它 = 停止服务。
4. 如果 8787 端口被占用，程序会自动改用 8788、8789……以窗口里显示的地址为准。

> 也可以直接双击 `index.html` 打开，但浏览器对本地 `file://` 页面的安全限制可能导致缩略图无法渲染，**建议始终用 `启动PDF工具.bat` 启动**。

环境要求：Windows + 系统自带的 PowerShell（Win10/11 默认就有），无需安装 Python、Node.js 或任何软件。

---

## 二、基本流程

1. **添加文件**：点击「＋ 添加 PDF」，或把 PDF 直接拖进右侧页面区域。
   可以一次添加多个 PDF，它们会合并到同一份页序里；同一文件也可重复添加。
2. **整理页面**：
   - 拖动缩略图调整顺序（拖动时会显示插入位置指示线）。
   - 单击选中；`Shift` 或 `Ctrl` 点击连选；`Ctrl+A` 全选。
   - 用左侧「页面操作」或快捷键删除、旋转、复制、插入空白页、仅保留选中页。
3. **调整版式**（可选）：左侧「统一页面尺寸」「裁剪 / 留白」。
4. **导出**：点击右上角「导出 PDF」，选择范围、拼版、拆分方式后开始导出。
   只需所选页面时，也可直接点「导出选中页」。

左侧「源文件」列表会显示每个 PDF 被保留了多少页，点 `✕` 可移除该文件的所有页面。

## 三、功能说明

### 页面整理
| 操作 | 说明 |
| --- | --- |
| 拖动排序 | 拖到目标位置松开，插入线指示落点 |
| 删除 | 从输出中移除页面（可撤销） |
| 左转 / 右转 | 每次 90°，可累计 |
| 复制 | 在选中页之后插入一份副本 |
| 插入空白页 | 在选中页之后插入一张与当前页同尺寸的空白页 |
| 仅保留选中 | 一次性删掉未选中的页面 |
| 撤销 / 重做 | 所有页面操作都可撤销、重做 |

### 统一页面尺寸
把选中页（未选中时=全部页）改成指定纸张：A4 / A4 横向 / A3 / A3 横向 / A5 / Letter / 自定义毫米尺寸。

- **内容方式**：等比适应（推荐，不变形）/ 拉伸填满 / 原始大小（不缩放，超出部分会被裁掉）。
- **对齐**：居中、上下左右、四角，共 9 种。
- 只修改页面外框与内容位置，**原有文字仍是可选中、可搜索的矢量文字**。

### 裁剪 / 留白
按页面的**显示方向**（已考虑页面旋转）从四边裁掉指定毫米数。

- 填**正数**＝向内裁剪；填**负数**＝向外加白边。
- 快捷按钮：清零 / 5mm / 10mm / 15mm。
- 点「还原」可撤销该页的尺寸与裁剪设置。
- 同理，裁剪只是改变页面可视区域，不会删掉或重新压缩内容。

### 拼版（N-up，打印用）
导出时可选 2 / 4 / 6 / 9 页合一，纸张支持 A4 / A4 横向 / A3 / A3 横向 / 跟随第一页，并可设置页间距与细边框。
适合把讲义、幻灯片等小页面拼到大纸上打印。拼版后的页面是图片式的页面对象，正文文字不再可搜索。

### 拆分 / 合并
- **合并**：一次添加多个 PDF，或把同一 PDF 添加多次，即可交叉排序后导出为一份。
- **拆分**：导出时可选
  - 每 N 页一个文件；
  - 按页码范围分段，如 `1-3,4-6,7-`（最后的 `7-` 表示第 7 页到末尾）。
  多份结果会自动打包成一个 **ZIP** 下载。

### 导出
- 可选导出「全部页面」或「仅选中的页面」。
- 可自定义文件名。
- 默认导出保留原始矢量内容与原页面尺寸/旋转；只有应用了「统一尺寸/裁剪/拼版」的页面才会被改写。

## 五、已知限制

- **不支持的 PDF**：加密 / 需要密码的 PDF、部分损坏文件会读取失败并提示。
- **不做文字编辑**：不能修改正文文字、表单、批注、签名等内容。
- **不压缩体积**：导出体积通常与源文件相近；多份 ZIP 不会额外压缩 PDF 内部数据。
- **大文件受内存限制**：页面全部在浏览器内存中处理，建议单次处理总量 **200 MB 以内**；超大文件可能卡顿或失败。
- **拼版页面不可搜索**：N-up 会把页面绘制为对象，文字不可选。
- **裁剪不改内容**：只是改变页面可视区域（CropBox），被裁掉的内容仍在文件里，可用其他工具恢复。
- **导出为 ZIP 时**：多文件打包由内置模块完成，个别老解压软件若报错，请用系统自带解压或 7-Zip 打开。
- **界面为中文**，仅在 Windows + Edge/Chrome 上验证；其他浏览器未做完整测试。

## 六、常见问题

**双击 bat 没反应 / 一闪而过？**
确认 `tools\serve.ps1` 与 `vendor\`、`js\`、`css\` 目录都在原位，不要单独移动 bat 文件。

**浏览器显示「无法访问此网站」？**
命令行窗口是否已关闭？重新双击 `启动PDF工具.bat`。若杀毒软件拦截了 PowerShell，请放行本目录。

**缩略图空白？**
请确认是通过 bat 以 `http://127.0.0.1:…` 打开的，而不是 `file://`。首次打开大文件时缩略图会按需加载，滚动到可见位置即可。

**端口被占用？**
不用处理，程序会自动顺延到 8788 等端口，以窗口显示的地址为准。

**文件会被上传吗？**
不会。除了打开本机 `127.0.0.1` 上的页面与本地脚本，不发起任何外部网络请求。

## 八、分发给其他人（离线使用）

已经生成好 **`发布/PDF页面整理-便携版.zip`**（约 640 KB），把这个 ZIP 发给对方即可。

对方的使用步骤：

1. 解压 ZIP，得到 `PDF页面整理` 文件夹（**不要只解压出 bat，也不要打散目录结构**）。
2. 双击 `启动PDF工具.bat`，浏览器会自动打开。
3. 保持命令行窗口开启，用完关掉即可。

注意事项：

- 对方需要 **Windows 10/11** 和系统自带的 PowerShell，无需安装其他软件。
- 邮件网关或聊天软件可能拦截包含 `.bat` 的压缩包，若发送失败，改用网盘或直接传文件夹。
- 压缩包内使用 UTF-8 文件名；极老的解压软件可能把中文显示成乱码，请用 Windows 自带解压、7-Zip 或 Bandizip。
- 从微信 / 邮件 / 网盘下载的 ZIP 可能带「来自 Internet」标记。若双击 bat 没反应，先右键 ZIP →「属性」→ 勾选「解除锁定」，再解压；或解压后在 PowerShell 中执行
  `Get-ChildItem -Recurse | Unblock-File`。
- 个别杀毒软件会拦截「PowerShell 启动本地服务」，选择允许即可；本程序不联网、不上传文件。
- 如果以后修改了程序文件，重新打包时请保持目录结构，并排除旧的 `发布` 文件夹和 `samples`（可选）。
- **Mac / Linux 用户**没有 bat，可在文件夹里执行 `python3 -m http.server 8787`，再打开 `http://127.0.0.1:8787/`（需要已安装 Python）。

## 九、部署到网站（在线使用）

这是一个**纯静态前端应用**：没有后端、数据库、账号系统，也不需要构建步骤。上传静态文件即可运行。

### 需要上传的文件

```
index.html
css/
js/
vendor/
```

`启动PDF工具.bat`、`tools/`、`samples/`、`README.md` 在线运行时**不需要**上传。

所有资源都使用相对路径（`css/style.css`、`vendor/pdf.worker.min.js`），因此可以部署在域名根目录，也可以放在子目录（如 `https://example.com/pdf/`），不用改代码。

### 方式一：GitHub Pages

1. 新建一个仓库，把上面 4 项上传到仓库根目录。
2. 仓库 **Settings → Pages → Build and deployment**，Source 选 `Deploy from a branch`，分支选 `main`、目录选 `/ (root)`。
3. 等一两分钟，访问 `https://用户名.github.io/仓库名/`。
4. 免费版仓库需要是 Public；Pages 自动提供 HTTPS。

### 方式二：Netlify / Cloudflare Pages / Vercel

- 打开 Netlify Drop（`app.netlify.com/drop`），把包含上述 4 项的文件夹直接拖进去即可，无需填构建命令。
- Cloudflare Pages / Vercel 同理：上传静态目录，构建命令留空，输出目录填 `.`。
- 若使用 Cloudflare，建议关闭 **Rocket Loader**（它会延迟加载脚本，可能导致 PDF 渲染失败）；Auto Minify 对已压缩的 vendor 文件意义不大。

### 方式三：自己的服务器（Nginx）

把 4 项文件放到 `/var/www/pdf-tool/`，然后：

```nginx
server {
    listen 80;
    server_name pdf.example.com;
    root /var/www/pdf-tool;
    index index.html;
    charset utf-8;

    location / {
        try_files $uri $uri/ =404;
    }

    # 可选：静态资源缓存
    location ~* \.(js|css|pdf)$ {
        expires 7d;
        add_header Cache-Control "public";
    }
}
```

HTTPS 建议用 Caddy 自动证书，或 `certbot --nginx`。

### 在线部署后的注意事项

- **文件仍然不会上传**：PDF 只在本机浏览器内存中处理，服务器只负责发送网页和脚本，收不到 PDF 内容。但服务器访问日志会记录 IP、访问时间等常规信息。
- **没有登录和权限控制**：任何拿到网址的人都能使用。需要私有化时，请在托管平台加访问控制（如 Cloudflare Access、Netlify 密码保护），或在 Nginx 上加 Basic Auth。
- **不要上传 `samples/` 或真实业务 PDF** 到公开站点。
- 首次加载约 **2 MB**（主要是 `vendor/` 里的两个 PDF 库），之后会被浏览器缓存；建议服务器开启 gzip / brotli。
- 部署后请用 **HTTPS** 访问，现代浏览器对本地文件、Worker、剪贴板等能力在 HTTP 下限制更多。
